# Math Quest test cheat codes

The test console starts a sandbox gameplay session. Answers, rewards, stars,
unlocks, currency, achievements, and construction progress are not saved.

| Cheat code | Destination |
| --- | --- |
| `MQ-LVL-01` | World 1 · Level 1 — Single-Digit Addition |
| `MQ-LVL-02` | World 1 · Level 2 — Single-Digit Subtraction |
| `MQ-LVL-03` | World 1 · Level 3 — Single-Digit Multiplication |
| `MQ-LVL-04` | World 1 · Level 4 — Single-Digit Division |
| `MQ-LVL-05` | World 1 · Level 5 — Grand All-Operations Boss Challenge |
| `MQ-LVL-06` | World 2 · Level 6 — Two-Digit Addition |
| `MQ-LVL-07` | World 2 · Level 7 — Two-Digit Subtraction |
| `MQ-LVL-08` | World 2 · Level 8 — Two-Digit Multiplication |
| `MQ-LVL-09` | World 2 · Level 9 — Two-Digit Division |
| `MQ-LVL-10` | World 2 · Level 10 — Two-Digit Boss Challenge |
| `MQ-LVL-11` | World 3 · Level 11 — Ratio Realm |
| `MQ-LVL-12` | World 3 · Level 12 — PEMDAS Peak |
| `MQ-LVL-13` | World 3 · Level 13 — Ratio & Operations Trail |
| `MQ-LVL-14` | World 3 · Level 14 — Multi-Step Mountain |
| `MQ-LVL-15` | World 3 · Level 15 — Puzzle Peak Boss Challenge |
The flask button is available automatically in debug builds. To enable it in
a release/profile build, run with:

```shell
flutter run --dart-define=ENABLE_TEST_CHEATS=true
```

Codes are case-insensitive; spaces and underscores are accepted in place of
hyphens.
